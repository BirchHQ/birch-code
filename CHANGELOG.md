# Changelog

All notable changes to Birch are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

Installers for every version are published on the [Releases](https://github.com/BirchInnovation/birch-code/releases) page and delivered automatically through the built-in updater.

## [0.22.8] — 2026-08-04

### Fixed

- Inbox: merged pull requests are now retired from the inbox even when a provider feed is permanently incomplete (for example, an Azure DevOps project the account cannot read).
- Recent repositories are sorted stably by name instead of reshuffling between runs.

## [0.22.7] — 2026-07-31

### Fixed

- Windows: handle the output format of current Git for Windows builds.
- Windows: links clicked inside a Codex terminal now open in the default browser instead of a new app window.
- Inbox: Azure DevOps work items now display their task hierarchy correctly.

---

Entries start at 0.22.7. Earlier versions predate this changelog.
